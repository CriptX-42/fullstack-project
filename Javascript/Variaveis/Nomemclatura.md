### Regras


- Camel Case para variáveis e funções

```
let nomeCompleto;
function calcularTotal() {}
```


- Pascal Case para classes e construtores

```
class Usuario {}
function ContaBancaria() {}
```


- Constantes em UPPER_CASE

```
const TAXA_JUROS = 0.05;
const PI = 3.14159;
```

- Prefixo para booleanos**
- Para variáveis booleanas, use prefixos como `is`, `has`, `can` ou `should`.

```
let isAtivo = true;
let hasPermissao = false;
```


- Prefixo para funções assíncronas
- Funções `async` podem ter prefixo `fetch`, `get`, `load` ou `async`.

```
async function fetchDados() {}
```
