### O que são?
São basicamente funções que já vem prontas no javascript. Não precisamos importar nada.

Podemos organizar por categorias.

Globais, Objetos matemáticos e numéricos, Datas, Arrays, Funções para erros, Tipos e conversões.

### 📌 **Funções Globais**

Estas estão disponíveis diretamente no escopo global:

- `eval()` – avalia uma string como código JavaScript (⚠️ perigoso e raramente recomendado)
    
- `isNaN()` – verifica se um valor é `NaN`
    
- `isFinite()` – verifica se o valor é um número finito
    
- `parseFloat()` – converte uma string para número decimal
    
- `parseInt()` – converte uma string para número inteiro
    
- `decodeURI()` / `decodeURIComponent()` – decodificam URIs
    
- `encodeURI()` / `encodeURIComponent()` – codificam URIs


### 🧮 **Objetos Matemáticos e Numéricos**

- `Math.random()` – retorna número aleatório entre 0 e 1
    
- `Math.floor()` – arredonda para baixo
    
- `Math.ceil()` – arredonda para cima
    
- `Math.round()` – arredonda para o inteiro mais próximo
    
- `Math.max()` / `Math.min()` – retorna o maior/menor número
    
- `Math.abs()` – valor absoluto
- 
### **Funções para Erros**

- `throw` – lança um erro
    
- `try...catch` – tratamento de erros

### 🧪 **Tipos e Conversão**

- `typeof` – retorna o tipo de dado
    
- `instanceof` – verifica instância
    
- `Boolean()`, `Number()`, `String()` – conversões explícitas
