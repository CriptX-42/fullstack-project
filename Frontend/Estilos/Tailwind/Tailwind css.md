## Definição

Lembra do bom e velho boostrap? então, não tem nada a ver com isso.

Mas alguns elementos são bem parecidos. Basicamente trazemos classes utilitárias para nós usarmos dentro do nosso html. Lembra disso? Nada de novo no front.


Um exemplo simples disso:
![[Pasted image 20250405175906.png]]


![[Pasted image 20250405180203.png]]



```
<div class="bg-gray-800 px-100 py-100 flex-col gap-4 whitespace-break-spaces">

<div class="bg-amber-300 px-5 py-8 " ></div>

<div class="bg-amber-300 px-5 py-8" ></div>

</div>
```




> [!Warning] Elementos basicos
```
m- margin (seletor)
p- padding (seletor)
h- hight (numero)
w- width (numero)
```
