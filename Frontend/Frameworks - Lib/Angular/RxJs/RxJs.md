### Reactive Extensions for JavaScript

Uma biblioteca muito robusta para programação reativa, baseada em observáveis. Usamos ela principalmente em fluxos assincronos como chamadas `HTTP`, eventos de UI e streams de dados em tempo real
Ela conta com alguns operadores como `map`, `filter`, `mergeMap`, `catchError`, `debouceTime` e etc.
Usamos ela principalmente para gerenciar assinaturas de serviços `HttpClient`, eventos de formlários (`FormControl.valuesChanges`), webSockets e entre outros.
